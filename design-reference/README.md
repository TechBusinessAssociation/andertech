# Design reference (not live)

Mockups kept for style reference while designing the real site. **Nothing in
this folder is wired into the app** — no page imports or links to these
files, and they are not in `/public`, so they are never served by the site
or shipped in the build.

## Status: not cleared for use

- `web-asset-kit-mockup.png` and `hero-mockup.png` are AI-generated concepts,
  not a confirmed logo or brand kit.
- Both use "Anderson" / "UCLA Anderson" branding and imagery. Per the root
  `CLAUDE.md`: **do not use UCLA or Anderson logos, marks, or "ucla" in
  domain names until the club has confirmed Anderson's branding rules.**
  That confirmation hasn't happened yet.
- The official club name and logo are still an **open decision** (see
  `CLAUDE.md` → "Open decisions").

Treat these as mood-board input (layout, color pairing, type pairing) —
not as the club's logo or wordmark — until the board confirms branding
with Anderson student affairs and a real logo is approved.
